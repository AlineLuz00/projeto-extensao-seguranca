# Projeto de Extensão - Sistemas de Informação e Sociedade

## Tema
Inclusão Digital e Segurança da Informação

## Objetivo

Promover a conscientização da comunidade sobre segurança da informação, proteção de dados pessoais e uso seguro da internet.

## Conteúdos abordados

- Criação de senhas seguras
- Identificação de golpes virtuais
- Proteção de dados pessoais
- Uso responsável das redes sociais
- Inclusão digital
